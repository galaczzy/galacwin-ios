# GalacWin iOS: origin and distribution notice

GalacWin iOS is a modified fork of [Madeira by Will Faust](https://github.com/willfaust/Madeira),
initially based on commit `c2c1b03a9e36ef986c980b9eae3c14d05a372db1`.
It is not an independent implementation. This fork is maintained separately
by `galaczzy`; the original author and the other upstream contributors have
not endorsed or certified it.

The public fork was prepared on 2026-11-01. Its changes include security
review controls, pinned build inputs, removal of packaged diagnostic programs,
and distinct public-facing branding. The source tree was published as a new
root commit so that the review workspace's private Git history is not exposed.
The original project's copyright notices, `LICENSE`, `COPYING`,
`LICENSE-EXCEPTION.md`, `THIRD-PARTY-NOTICES.md`, component license files, and
submodule provenance are preserved. The GPL-3.0-or-later terms apply to the
covered source. The maintainer's separate additional permission for changes
whose rights they hold is in `LICENSE-GALACWIN-EXCEPTION.md`. Component-specific
licenses and the original author's additional permission apply only within
their stated scope. Internal file
names and identifiers may still contain “Madeira” because the program was
derived from that source.

The original banner and app icon are not used for this fork's public identity.
There is no approved IPA or device-validated build. See `SECURITY.md` and the
open licensing questions in `docs/LICENSING.md` before distributing binaries.
The renamed project and preserved notices reduce confusion; they are not a
legal clearance or a malware guarantee.
